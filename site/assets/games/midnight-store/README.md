# 长夜便利店 · NIGHTLONG MART

> 一部可以在浏览器里直接玩的 3D 第一人称心理恐怖短篇。
>
> 凌晨三点以后，客人会变多。他们大多很有礼貌。

---

## 立刻开始

1. 打开本文件夹。
2. 双击 **`index.html`**（或双击 `启动游戏.bat`）。
3. 点击标题画面左下角的 **开始新班**。
4. 浏览器会请求锁定鼠标——点击画面允许即可。
5. 建议：全屏、耳机、低光环境。

游戏完全离线，不需要联网，不需要安装任何东西，也不需要启动服务器。
所有 3D 模型、贴图、音效都在本地由代码生成或内嵌。

如果双击后浏览器仍然拦截本地文件，可以在此文件夹里打开终端运行：

```bat
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 玩法

你是长夜路 24H 便利店的夜班店员，林岳。

从 22:00 到 04:00，接待客人、核对口令、检查证件、扫描商品、收钱。
有些“客人”不是人。它们会模仿声音、脸、记忆，甚至记忆里的顺序。
认出来，然后在它动手之前，用柜台下面的枪解决它。

**枪里只有六发子弹，一个夜班不会补给。**

### 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `W A S D` |
| 环视 | 鼠标 |
| 交互 / 接待 | `E` |
| 观察（按住） | `Q` |
| 拔枪 / 收枪 | `G` |
| 瞄准 | 鼠标右键 |
| 开枪 | 鼠标左键 |
| 手电筒 | `F` |

| 暂停 | `Esc` |
| 对话选项 | `1` – `6` 或鼠标点击 |
| 继续 / 跳过文字 | `空格` / `Enter` |

### 如何判断

夜班守则写在手册里（游戏内按 `Tab`）。核心只有几条：

- **先问口令，再看证件。** 口令每晚由电台播报，电台内容会记进日志。
- 有些东西**不会眨眼**，**不会呼出白气**，或者**在玻璃里没有影子**。
- 客人说“我能进来吗”的时候，不要邀请他。
- 没有听见门铃就出现的人，不是客人。
- 枪在柜台下面。**不要打人。打错了，你就不再是店员。**

注意：口令正确不代表安全。有些东西听过电台。

### 夜班流程

- 每夜从 22:00 开始，04:00 结束（游戏内时间会加快）。
- 柜台前有客人时按 `E` 接待。对话中按 `G` 可以直接拔枪、中断对话。
- 按住 `Q` 观察柜台前的人。观察得太久，它会发现你在看它。
- 客人会等你，但耐心有限。有些东西等得不耐烦时，会自己走过来。
- 柜台上的监控可以查看店内（靠近监控按 `E`），停电的夜晚尤其有用。
- 后仓门可以打开；里面有便签、配电箱和一些不该看见的东西。
- 击败的伪人不会留下尸体，只会留下一摊黑色的水。人则会留下别的。

### 进度与结局

- 每完成一夜自动解锁下一夜，进度保存在浏览器本地。
- 共五夜，三个结局。标题画面的“夜班记录”可以重玩已解锁的夜。
- 如果失败，重试不会写入记录。

## 内容警告

本作包含：

- 闪烁的灯光与突然的画面变化
- 突然的巨响、枪声、低频压迫音
- 心理恐怖、跟踪、模仿、失去亲人的主题
- 非写实但涉及人体变形的伪人形象

如果你对闪烁画面敏感，请在系统设置里关闭动画，或不要游玩。
建议佩戴耳机；不建议在深夜独自用最大音量游玩。

---

## 画质与性能

游戏针对普通集成显卡设计：

- 无实时阴影、无屏幕空间反射等昂贵后处理；玻璃、雨、监控都是低成本实现。
- 默认分辨率上限为 1×，画质“低”会自动降到 0.72×；帧率过低时会自动降低一点分辨率。
- 画质可在标题或暂停菜单的“设置”里调整（低 / 中 / 高）。
- 如果仍然卡顿，选择“低”，或把浏览器窗口缩小。
- 设置会自动保存在本地；中文语音使用系统 TTS，没有中文语音时会自动退化为字幕。

## 技术说明

- 纯 HTML / CSS / JavaScript，`three.js r140` 本地内嵌。
- 写实人头模型：Lee Perry-Smith 头部扫描（CC BY 3.0），贴图经过重新绘制以制作睁眼、伪人表情等变体。
- 便利店、街道、产品、证件、海报、音效、配乐全部由代码程序化生成。
- 人脸在运行时由 Canvas 绘制，证件照会复用同一张面部贴图，所以证件照与本人一致——包括伪人。
- 3D 人头与身体由 GLB 解析后实时组合；无需外部资源。

## 测试提示

- 想直接体验某一夜：在地址栏的 `index.html` 后面加上 `?night=3`（1–5）。
- 游戏中按 `]` 可以快进 30 分钟（隐藏调试键）。
- 如果没有声音，请先点击画面一次（浏览器需要用户手势才能启动音频）。
- 如果鼠标没有锁定，点击游戏画面即可；按 `Esc` 会释放鼠标并暂停。
