给替班的人看的。看完再去点「开始值班」，能少掉不少理智。

## 四个动作

| 动作 | 键 | 实际效果 |
| --- | --- | --- |
| 递货 | 1 | 收钱交货。对着不该卖的人用会掉理智、掉钱，并记一次事故 |
| 查证件 | 2 | 揭示对方的底细，代价是 1.4 秒的耐心；同一个人查第二次只会更快翻脸 |
| 手电 | 3 | 耗 1 格电。对影子有效，对普通人是冒犯 |
| 请他走 | 4 | 结束这一单。多数时候最稳，但也会少赚一单 |

## 来客

| 类型 | 画面上看得出来吗 | 怎么处理 |
| --- | --- | --- |
| 普通顾客 | 看得出是普通顾客 | 直接递货 |
| 熟客 | 鸭舌帽，会多给小费 | 直接递货；查证件他也不生气 |
| 醉汉 | 站不稳，身体在晃 | 请他走最稳。卖酒有四成会出事 |
| 未成年 | 个子矮一截 | 先查证件，再请他走 |
| 缺证 | 看不出来 | 先查证件。他说明天补钱，明天不会来 |
| 兜帽客 | 兜帽压得很低，看不见眼睛 | 查证件会看到对不上的照片；请他走 |
| 影子 | 纯黑，眼睛是红的，脚下有东西在渗 | 手电。递货是最坏的一手 |

## 资源

- **营业额**：可以变成负数，没人拦你。
- **理智**：站着不动也会掉，整班大约掉 18 点；一次事故掉 8–26 点。归零就换班。
- **电量**：5 格起步，上限 8 格；03:00 与 05:00 各补 2 格。

## 03:33

后门会有人敲，三下，很慢。这时四个动作只剩两个：**开门（1）** 和 **别出声（4）**。

别出声，理智回一点；开门，掉 30 点理智，门外只有一件湿透的雨衣。九秒不理会，门锁会自己转一下。

## 评级

| 等级 | 条件 |
| --- | --- |
| S | 营业额 ≥ 800 且理智 ≥ 70 |
| A | 营业额 ≥ 600 |
| B | 营业额 ≥ 400 |
| C | 其余：上完了，就这样 |

## 为什么是 WebAssembly

判定与时间在 `shift.wasm` 里跑，前端只做三件事：把状态读出来、把画面画出来、把按钮接进去。WASM 里没有一行中文，也没有 DOM 访问——所以它可以在浏览器里跑，也可以直接拿 Node 跑测试。

::: note 一句实话
这个版本是按同一题材重写的，不是原 Unity 工程的移植。原工程没有导出 WebGL 构建，Windows 的可执行文件不能直接变成网页。
:::
